# create-truecanvas

```bash
npm create truecanvas@latest my-app
```

Creates a Next.js app (TypeScript, Tailwind, App Router) with [Truecanvas](https://github.com/Nathandona/truecanvas) set up: the dev dependency, `next.config` wrapped, a first canvas, and `.mcp.json` so Claude Code and Cursor connect. Then:

```bash
cd my-app
npm run canvas
```

Works with npm, pnpm (`pnpm create truecanvas`), yarn and bun.
